# 2048 — Console Game (C++)

Classic 2048 puzzle game implemented in C++ for the Windows console.

## Features

- Full game logic with score tracking
- Save and load best score
- Simple menu interface

## Controls

- `W` — Move up
- `A` — Move left
- `S` — Move down
- `D` — Move right
- `X` — Exit game

## Compilation

Open the solution file (`.sln`) in Visual Studio and build the project.

## Requirements

- Windows OS
- Visual Studio 2022 or later
- C++20

## How to play

Combine tiles with the same number to reach **2048**. The game ends when no moves are left.
